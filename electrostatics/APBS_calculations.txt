APBS ELECTROSTATIC POTENTIAL CALCULATION
=======================================

Purpose
-------
Calculate the electrostatic potential map of full-length UDG, including its
N-terminal tail, using the default parameters generated by the APBS Web Server.
This calculation reproduces the electrostatic potential presented in Figure 3
of the associated article.

Required files
--------------
- UDG_tail.pqr: full-length UDG structure prepared with PDB2PQR
- UDG_tail_APBS_default.in: APBS input generated for this structure

Calculation procedure
---------------------
1. Open the APBS Web Server.
2. Submit UDG_tail.pqr together with UDG_tail_APBS_default.in.
3. Use the default APBS parameters listed below without manually changing the
   automatically generated grid dimensions, box lengths, or grid centers.
4. Run the calculation.
5. Download the OpenDX electrostatic potential map.
6. Rename the output descriptively, for example:
   - UDG_tail_APBS_default.dx
7. Keep the APBS input, output map, and calculation log together.

APBS parameters
---------------
Equation and solver:

   mg-auto
   lpbe
   bcfl sdh

Dielectric constants:

   pdie 2.0000
   sdie 78.5400

Molecular surface and charge discretization:

   srfm smol
   chgm spl2
   sdens 10.00
   srad 1.40
   swin 0.30

Temperature:

   temp 298.15

Automatically generated computational grid
------------------------------------------
The grid was automatically centered on the full-length UDG structure:

   dime   193 193 257
   cglen  141.6273 130.2183 191.7498
   fglen  103.3102 96.5990 132.7940
   cgcent mol 1
   fgcent mol 1

The coarse- and fine-grid dimensions are expressed in angstroms. These
parameters correspond to fine-grid spacings of approximately:

   x: 103.3102 / (193 - 1) = 0.538 A
   y:  96.5990 / (193 - 1) = 0.503 A
   z: 132.7940 / (257 - 1) = 0.519 A

The spatial resolution is therefore approximately 0.50 A along the three grid
directions.

Relevant calculation and output settings
----------------------------------------

   mol 1
   calcenergy total
   calcforce no
   write pot dx UDG_tail_APBS_default

The output is an OpenDX electrostatic potential map that can be loaded together
with the full-length UDG structure in molecular-visualization software.

Complete calculation block
--------------------------
The APBS calculation block can be reproduced as follows:

   elec
       mg-auto
       dime 193 193 257
       cglen 141.6273 130.2183 191.7498
       fglen 103.3102 96.5990 132.7940
       cgcent mol 1
       fgcent mol 1
       mol 1
       lpbe
       bcfl sdh
       pdie 2.0000
       sdie 78.5400
       srfm smol
       chgm spl2
       sdens 10.00
       srad 1.40
       swin 0.30
       temp 298.15
       calcenergy total
       calcforce no
       write pot dx UDG_tail_APBS_default
   end
