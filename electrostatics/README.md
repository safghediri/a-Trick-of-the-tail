# Electrostatic analysis of UDG

This folder contains the structures and protocols used to analyse the charge distribution and electrostatic potential of human uracil-DNA glycosylase (UDG), including its N-terminal tail.

## Workflow

### 1. Structure preparation with PDB2PQR

The UDG structures were prepared using PDB2PQR with the AMBER force field at pH 7. PDB2PQR assigns atomic charges and radii and generates the PQR structures required for the APBS and DelPhi calculations.

The complete preparation procedure is provided in PDB2PQR_input_preparation.txt.

### 2. Charge analysis of the UDG tail

The distribution of charged residues along the UDG N-terminal region was analysed using EMBOSS and CIDER. This analysis identifies positively charged regions, including the RKR motif at residues 17–19.

The sequence and analysis procedure are provided in tail_charge_analysis_EMBOSS_CIDER.txt.

### 3. APBS calculation

The PQR structure generated with PDB2PQR was used as input for APBS. APBS calculates the electrostatic potential by solving the linearized Poisson–Boltzmann equation.

The calculation parameters, computational grid, and reproduction procedure are provided in APBS_calculations.txt.

### 4. DelPhi calculation

The same PQR structure was also analysed using DelPhi to obtain an independent electrostatic-potential calculation for comparison with APBS.

The DelPhi settings and calculation procedure are provided in DelPhi_calculations.txt.

### 5. Visualization and comparison

The electrostatic-potential maps generated by APBS and DelPhi were visualized and compared using UCSF Chimera. The same colour convention and potential range were applied to the different maps.

The visualization procedure is provided in Chimera_visualization_and_comparison.txt.

## Files included

* `udg.pdb`: UDG structural model without the N-terminal tail.
* `udg_tail.pdb`: Full-length UDG model containing the N-terminal tail.
* `PDB2PQR_input_preparation.txt`: Preparation of the structures for the electrostatic calculations.
* `tail_charge_analysis_EMBOSS_CIDER.txt`: Analysis of the charge distribution along the UDG tail.
* `APBS_calculations.txt`: APBS parameters and calculation procedure.
* `DelPhi_calculations.txt`: DelPhi parameters and calculation procedure.
* `Chimera_visualization_and_comparison.txt`: Visualization and comparison of the electrostatic-potential maps.
* `Electrostatics.pdf`: Electrostatic-analysis figures and results.
