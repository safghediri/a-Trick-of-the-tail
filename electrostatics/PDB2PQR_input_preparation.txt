INPUT PREPARATION WITH PDB2PQR
==============================

Purpose
-------
Prepare the charge and radius assigned structure of full length UDG, including
its N-terminal tail, for electrostatic potential calculations with APBS.

Required input structure
------------------------
- UDG_tail.pdb: complete UDG structure including the N-terminal tail

Procedure
---------
1. Open the PDB2PQR Web Server.
2. Upload UDG_tail.pdb.
3. Select the following settings:
   - pH: 7.0
   - Force field: AMBER
   - Output naming scheme: Internal
4. Run PDB2PQR.
5. Download:
   - the generated PQR structure
   - the APBS input file generated by the server
6. Rename the files descriptively:
   - UDG_tail.pqr
   - UDG_tail_APBS_default.in

Output and use
--------------
- UDG_tail.pqr contains the atomic coordinates, charges, and radii assigned by
  PDB2PQR.
- UDG_tail_APBS_default.in contains the default APBS parameters automatically
  generated for this structure.
- These files are used to reproduce the APBS electrostatic potential calculation
  presented in the article.
